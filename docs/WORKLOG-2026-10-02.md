**Decisions / deviations**

- **Fonts fetched live rather than vendored by hand.** The plan calls for self-hosted
  woff2; there is no browser available here to download them, so a Node script hit the
  Google Fonts CSS API with a modern UA, parsed the `@font-face` blocks by their subset
  comments, and kept only latin + latin-ext. Four files, not the seven-plus subsets Google
  offers. The script was scratch and has been deleted; the `.woff2` files are committed.
- **No `vendor/` directory.** aphelion and fivestarrepairs both need one because they
  bundle qrcode via esbuild. This site has no such dependency, so `package.json` carries no
  `devDependencies` and there is no build artifact to check in.
